Custom vocabulary

A new settings row that teaches Whisper the spellings you care about. Design for approval, nothing built yet.

What you will see

The settings window gets a seventh row, Custom vocabulary, with tag chips: type a word, press Enter, it becomes a chip; click the x to remove it. Every add or remove saves immediately, same as the toggles. The list starts empty.

What happens when you dictate

You speak"how do I prompt Claude"
→
UploadAudio + your word list ride in the same request
→
WhisperReads the list as context, so "Claude" beats "clawed"
→
PasteCorrect spelling lands at your cursor

It is a bias, not a guarantee: a mumbled word can still come out wrong, but each listed word becomes the model's preferred interpretation whenever the audio is close.

With an empty list, the request is byte-for-byte what the app sends today. The optional AI-formatting pass is untouched either way.

Limits worth knowing

  • Roughly 150 words of budget. Whisper only reads the last ~224 tokens of the prompt; beyond that, the earliest words silently stop having any effect. The settings row will show a soft warning past 50 words rather than hard-blocking.
  • Spelling in, spelling out. The exact casing you type is what gets reinforced, so "OpenAI" must be entered as OpenAI.
  • Multi-word phrases are fine. A chip can hold "Claude Code"; the list is joined with commas either way.

How it gets verified

  • Unit tests: settings default/merge/roundtrip for the new list; the words-to-prompt join (trimming, dedupe); the upload includes prompt when words exist and omits it when the list is empty.
  • Manual check: add the five words, dictate a sentence containing them, confirm the spellings land correctly.
